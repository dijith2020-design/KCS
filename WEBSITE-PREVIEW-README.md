# Krishna Catering Services website preview

This branch contains a standalone, responsive HTML homepage concept. It keeps the existing `ASD` file untouched and adds `index.html` for preview. No framework or dependency was added.

## Original photo files to add

Create an `images/` folder at the repository root and add the original, unedited photos with these exact filenames:

- `kcs-logo.png` — KCS logo
- `kitchen-team.jpg` — original kitchen team / food-packing photo (homepage hero)
- `team-group.jpg` — original group photo (Our Team, Our Strength and Guest House Catering card)
- `industrial-canteen.jpg` — original dining hall / canteen photo (industrial and hygiene cards)
- `project-canteen.jpg` — original prefabricated modular canteen building photo

Use the originals as provided; do not apply AI enhancement, filters, or retouching. CSS crops images to fit the layout without changing the source files.
